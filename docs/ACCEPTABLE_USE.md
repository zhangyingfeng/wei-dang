# 可接受使用规则

本项目为本人内容备份和迁移而设计。

## 可以

- 导出当前登录账号本人已经发布过的公众号文章；
- 导出已经获得作者或权利人明确授权的内容；
- 将导出结果用于个人备份、格式迁移和自有网站；
- 在正常访问权限和合理请求频率内修改、研究本项目。

## 项目不支持

- 绕过验证码、登录验证、访问控制或反爬安全措施；
- 使用代理池、账号池或自动化手段规避限制；
- 获取付费、私密、已限制或未获授权的内容；
- 搜索、聚合或批量抓取其他公众号的内容；
- 批量收集读者、粉丝或其他个人信息；
- 对微信服务器造成异常负载或干扰其正常运行；
- 将他人文章或图片冒充为自己的作品。
