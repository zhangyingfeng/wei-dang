# 隐私说明

## 数据如何处理

- 应用在用户电脑上运行，本地服务只监听 `127.0.0.1`。
- 用户在应用内置的登录窗口中直接登录公众号后台；应用不要求在表单、终端或配置文件中填写密码或 Cookie。
- 登录会话由系统自带的 WebView 管理和持久化（macOS 上是 WKWebView），保存在 `~/Library/WebKit/` 下，本应用的后端服务不接触、不读取这份会话数据——真正代表用户身份的只有从登录窗口地址栏捕获的 `token`，接口请求本身也是在登录窗口自己的页面上下文里发起的，不经过后端服务。
- 文章和图片写入用户指定的本地目录。
- 项目不包含遥测、分析、广告、远程日志或开发者服务器上传功能。

## 导出内容

导出文件包含文章正文、原文链接、时间、公开互动数量（如接口返回）和图片。导出索引不保存账号昵称、简介或账号标识。失败报告可能包含文章标题、内容 ID 和失败图片地址，因为这些信息用于本地排错。

## 删除数据

- 想清除登录会话，点应用里的"退出登录"即可；也可以手动删除 `~/Library/WebKit/` 下对应的目录。
- 删除用户选择的导出目录可清除导出内容。
- 关闭应用后，运行内存中的登录 token 和任务状态随进程结束而消失。

## 使用者责任

不要提交或分享导出目录、Cookie、Token、日志或其他可能包含个人信息的文件。
