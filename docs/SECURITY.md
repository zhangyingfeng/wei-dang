# 安全策略

## 支持版本

安全修复只保证应用于最新发布版本。

## 报告安全问题

请使用 GitHub 仓库的"Private vulnerability reporting"功能私下报告安全问题。不要在公开 Issue 中发布 Cookie、Token、浏览器 Profile、真实导出内容或可利用细节。

## 凭证泄露

如果登录会话被意外提交或公开：

1. 立即从公开位置删除相关文件；
2. 在公众号后台退出相关登录会话（或在应用里点"退出登录"）；
3. 删除本地 `~/Library/WebKit/` 下对应的会话目录；
4. 从 Git 历史中清除敏感文件；
5. 不要只依赖最新一次提交中的删除操作。

## 不接受的安全相关功能

本项目不接受访问控制规避相关贡献（完整边界见 [ACCEPTABLE_USE.md](ACCEPTABLE_USE.md)），也不接受凭证采集或隐藏高频请求的贡献。
