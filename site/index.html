微档

本地归档你的微信公众号文章

「微档」即微信公众号作者归档。一个安全、开源的内容导出工具，帮公众号作者把自己账号下已经发布过的文章导出为 Markdown、Word 和本地图片。

从一个很具体的问题开始

公众号作者在长期创作之后，如何把自己的作品完整、安全地保存下来，并继续由自己控制。

微档的回答是：把作者自己的公众号创作，转换成开放、可读、可迁移、由作者自己保管的本地归档。

微档不是爬虫，是用户授权的归档工具

微档不采集别人的公众号内容，也不做大规模抓取——它只在你本人登录自己的公众号后台之后，把你自己账号下已经发布的文章搬到你自己的电脑上。没有你的登录、没有你的操作，微档什么也拿不到。拿大规模采集工具做对比，一眼就能看清楚：

问题大规模采集工具微档
抓别的公众号发布的内容可能大量采集不支持——只导出当前登录账号本人的文章
聚合多个公众号的数据常见否——每次只处理你自己这一个账号
绕开微信官方的验证码/风控可能不做——遇到验证码交给你本人处理
数据经过开发者的服务器可能不经过——本地直连微信后台，本地写文件
代理池 / 账号池可能使用不使用
保存位置可能进入第三方数据库你自己电脑上的文件夹

一句话总结：微档只做"帮你把自己的账号搬到自己的硬盘"这一件事，任何会让它变成内容聚合服务、大规模采集工具或访问控制绕过工具的能力，都不属于微档的产品范围。

这是独立开发的非官方项目，与微信/腾讯不存在隶属、合作、授权或认可关系。

目前只在 macOS（Apple Silicon）上完整测试，已通过 Apple Developer ID 签名与公证。详见 免责声明 · 可接受使用。

你会得到什么

导出结果是一个普通的本地文件夹，可以直接读、备份、迁移到自有网站。index.json 和 Markdown 被当作长期数据格式来维护。

Markdown 正文 Word 文档 index.json 索引 export-report.json 报告 本地化图片 
导出目录/
├── articles/           # 每篇文章一个 Markdown 文件
├── word/               # 每篇文章对应的 Word 文档
├── images/             # 正文里的图片，全部下载到本地
├── index.json          # 全部内容的结构化索引
├── export-report.json  # 总数 / 失败 / 跳过 / 已删除的完整报告
└── README.md           # 这份导出的说明

每个条目保留原文链接、创建与更新时间、封面等元数据。文章被作者本人删除时会被识别并标记，不会反复重试；中途退出或失败，指向同一个目录再次导出会跳过已经完成的部分。

怎么用

独立桌面应用，不需要安装 Node.js、Chrome 或任何开发工具。

1

下载并打开

从 GitHub Releases 下载 .dmg，拖进「应用程序」打开。打开后直接是导出设置界面。

2

登录公众号后台

点「开始登录」，在弹出的独立窗口里用手机扫码登录你自己的公众号后台。登录信息只留在本机。

3

选目录，导出

确认保存位置，点「开始导出」。每一项的进度都能看到，可以随时暂停、跳过某一项；完成后显示汇总，并可一键在访达中打开结果。

设计原则

正因为微档的定位是「用户授权的归档工具」，无论它发展到什么程度，都保持以下原则。

平台独立

微信公众号是当前的内容来源，但数据模型不永远绑定于某个平台的页面结构。

本地优先

作者应能取得自己的完整数据，并能在没有任何云服务的情况下继续使用。

安全隐私

登录信息、Cookie 和导出内容默认只保存在本机，不自动上传；不加入遥测、远程日志或用户内容上传。

开放格式

内容和元数据优先采用公开、可迁移的格式，不制造新的平台锁定。

隐私

这是微档最在意的一层，也是它和「一键搬运」类工具的根本区别。

  • 应用在你自己的电脑上运行，本地服务只监听 127.0.0.1。
  • 在应用内置的登录窗口里直接登录公众号后台，不需要在表单、终端或配置文件里填密码或 Cookie。
  • 登录会话由系统自带的 WebView 管理（macOS 上是 WKWebView），本应用的后端服务不接触、不读取——真正代表身份的只有从地址栏捕获的 token。
  • 文章和图片只写入你指定的本地目录。
  • 不包含遥测、分析、广告、远程日志或开发者服务器上传。
  • 点「退出登录」即可清除会话；删除导出目录即可清除导出内容。

详见 隐私说明。

路线图

记录方向和优先级，不代表功能已完成，也不构成发布时间承诺。

已完成

核心导出流程：登录窗口 + token 捕获、列表/正文抓取、图片本地化、Markdown/Word 落盘，用真实公众号账号完整验证过。

已完成

断点续传 + 已删除识别：中断或失败后再次导出会跳过已完成的项；文章被作者删除会被识别并标记，不会反复重试。

已完成

Apple 签名 + 公证：已用 Developer ID 证书签名并通过公证，下载后可直接打开，不再有 Gatekeeper 警告。

规划中

验证码 / 风控识别：目前的识别逻辑还没有被真实场景验证过，撞上时会给出清晰提示而不是静默失败。
